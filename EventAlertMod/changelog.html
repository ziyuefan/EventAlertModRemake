    • 全域冷卻事件同幀合併排程 (Frame-Level Cooldown Event Coalescing)：針對 SPELL_UPDATE_COOLDOWN、ACTIONBAR_UPDATE_COOLDOWN 與 BAG_UPDATE_COOLDOWN 等無法術 ID 負載之高頻全域事件實裝同幀合併調度，杜絕同一幀/Tick 內多次重複的全清單遍歷，極大平滑團隊副本與大秘境高負載環境下的幀率。
    • 原生光環字型大小即時熱套用修復 (Native Aura Font Size Live Hot-Apply & Zero Reload):
    • 徹底修復 Retail 12.1.0 原生光環 (Native Aura) 在設定介面調整「秒數倒數字型大小」、「堆疊層數字型大小」或「法術名稱字型大小」後無法即時反應、必須 /reload 才能生效的重大缺陷。
    • 實裝 NativeAuraRenderer 弱引用按鈕註冊池 (Weak Table Buttons Pool)，於光環按鈕初始化時安全保留 FontString 參照，暴雪銷毀按鈕時由 Lua GC 自動釋放，零記憶體洩漏。
    • 實裝 updateButtonFonts 零配額熱套用機制，拉動滑桿時直接調用 FontString:SetFont 原位更新畫面上所有活躍光環文字，零延遲、無需銷毀容器、不消耗 18 次配額，徹底擺脫 /reload 泥潭。
    • 優化 Options.lua 滑桿提交流程與文字通知路由，字型大小滑桿放開時不再觸發無謂的容器重建，杜絕觸發 18 次配額上限導致系統鎖死的隱患。
    • 統一全專案法術名稱字型大小取值邏輯，完善規則編譯器指紋 (buildVisualFingerprint) 與樣式快照 (snapshotStyle)，確保新舊光環按鈕字型大小 100% 一致。
    • 聊天框跳脫字元破裂修復 (Chat Pipe Escape Fix):
