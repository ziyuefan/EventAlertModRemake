# EAM UI Interactive Suite (現代化介面互動套件)

本技能規範 EventAlertMod 設定介面的佈局架構、吸附邏輯與操作反饋標準。

## 1. 階層吸附與同步聯動拖曳
- **APPEND 吸附架構**：主選單 ➔ 清單/排版/職業資源 ➔ 細部條件/批次輸入。
- 拖曳主視窗時，所有已開啟之附屬側窗自動同步平滑平移；關閉主視窗時透過 `safeClosePanel` 安全遞迴收合。

## 2. 側窗互斥與移動錨點
- 開啟任一二級側窗時，自動收合其他側窗，徹底防止畫面重疊混亂。
- 開啟排版視窗時自動亮起類別移動錨點框與經典奶牛頭預覽圖示。

## 3. 防丟鎖定與置中重置
- 主視窗啟用 `SetClampedToScreen(true)`，防止拖曳出螢幕外。
- 支援 `/eam reset`、`/eam center` 與小地圖按鈕中鍵點擊，一鍵將介面復位至螢幕正中央。

## 4. 全介面懸停提示 (`EAM.UI.setTooltip`)
- 在所有按鈕、核取方塊、滑桿、選單、輸入框統一配置繁中說明提示。
