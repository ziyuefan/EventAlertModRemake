EAM 實施導向摘要

WoW API

WoW API 是主要運行時 API 入口。 EAM rewrite 應優先從 API 系統找到對應的命名空間，而不是保留舊的全域包裝器。

重要三層：

WoW API
├─ API systems
│  ├─ C_UnitAuras
│  │  └─ AuraService
│  ├─ C_Spell
│  │  └─ CooldownService / SpellInfoService
│  ├─ C_Item
│  │  └─ ItemCooldownService
│  ├─ C_TooltipInfo
│  │  └─ low-frequency fallback only
│  └─ C_Secrets
│     └─ boundary checks

結論：

  • 12.x 只用於正式服 C_* 命名空間。
  • C_Secrets應集中封裝，不要散去每個UI功能。
  • C_TooltipInfo 是後備資料來源，而非熱路徑事實來源。

Lua API

Lua API 說明 WoW 使用 Lua 5.1 子集，且缺少作業系統/檔案 I/O 函式庫。

重要三層：

Lua API
├─ basic functions
│  ├─ pcall / xpcall
│  └─ type / select
├─ string
│  ├─ string.match / gsub / format
│  └─ WoW custom string helpers
├─ table
│  ├─ table.create
│  ├─ table.wipe
│  ├─ table.freeze
│  └─ table.isfrozen

結論：

  • string.match 在未確認安全性的秘密衍生性工具提示文字時不可用。
  • 熱路徑避免瞬態表、table.insert、大量pairs。
  • table.freeze 只用於不可變常數。

FrameXML API

FrameXML 函數 包含 UI helper、pool、EventUtil、TooltipUtil、LinkUtil 等。

重要三層：

FrameXML API
├─ Mixins / pools
│  ├─ CreateFramePool
│  ├─ CreateTexturePool
│  └─ CreateFontStringPool
├─ SharedXML
│  ├─ EventUtil
│  ├─ FrameUtil
│  └─ TooltipUtil
└─ UIParent / panels
   ├─ ShowUIPanel
   └─ Toggle*Frame

結論：

  • EAM 的 UI/IconPool.lua 可以參考暴雪礦池模式。
  • 請勿在戰鬥中呼叫會切換受保護面板的函數。
  • TooltipUtil 可作參考，但工具提示解析必須低頻且秘密安全。

小工具 API / 小工具腳本

Widget API 和 Widget script handlers 是 EAM 渲染器、EventRouter、調度器的基礎。

重要三層：

Widget API
├─ Frame
│  ├─ RegisterEvent
│  ├─ RegisterAllEvents
│  └─ SetScript
├─ Cooldown
│  ├─ SetCooldownFromDurationObject
│  ├─ SetCountdownFormatter
│  └─ SetCountdownMillisecondsThreshold
└─ FontString
   ├─ SetText
   └─ ClearText

Widget scripts
├─ Frame
│  ├─ OnEvent
│  └─ OnUpdate
├─ Button
│  ├─ OnClick
│  └─ PreClick / PostClick
└─ EditBox
   ├─ OnTextChanged
   └─ OnEnterPressed / OnEscapePressed

結論：

  • RegisterAllEvents 只適合 debug/datamining，不適合 EAM 運行時。
  • EAM 只應有一個 EventRouter OnEvent。
  • EAM 只應有一個排程器 OnUpdate。
  • Cooldown應承接DurationObject，不要讓Lua每幀算秒。

XML 架構

XML schema 說明 XML 可以建立 UI，但 Lua Widget API 也可以做大部分事情。

重要三層：

XML schema
├─ Ui
│  ├─ Include
│  └─ Script
├─ LayoutFrame
│  ├─ Size
│  ├─ Anchors
│  └─ Animations
└─ Frame
   ├─ Layers
   ├─ Frames
   └─ Scripts

結論：

  • 新架構可保留簡單的 XML 載入程序，但執行時間圖示應破解 IconPool。
  • 避免在XML內建立大量全域框架名稱。
  • 避免XML OnUpdate。

活動

Events / Category:API events 是 EventRouter 的事件來源。

重要三層：

Events
├─ UNIT_AURA
│  ├─ unitTarget
│  ├─ updateInfo.addedAuras
│  ├─ updateInfo.updatedAuraInstanceIDs
│  └─ updateInfo.removedAuraInstanceIDs
├─ cooldown events
│  ├─ SPELL_UPDATE_COOLDOWN
│  ├─ SPELL_UPDATE_CHARGES
│  └─ BAG_UPDATE_COOLDOWN
└─ combat boundary
   ├─ PLAYER_REGEN_DISABLED
   └─ PLAYER_REGEN_ENABLED

結論：

  • UNIT_AURA增量資料是AuraService核心入口。
  • 刪除了光環實例ID無法再查出完整的光環，服務要先快取安全摘要。
  • 脫戰刷新是邊界限制狀態的安排點。

CVar

控制台變數 說明 CVar 可以用 GetCVar / SetCVar / /console 管理，部分安全 CVar 不能在戰鬥中修改。

重要三層：

CVars
├─ query
│  ├─ GetCVar
│  ├─ GetCVarDefault
│  └─ C_CVar.GetCVarInfo
├─ mutation
│  ├─ SetCVar
│  └─ /console
└─ reset
   ├─ cvar_default
   └─ cvar_reset

結論：

  • EAM 無法依賴改 CVar 完成功能。
  • 秘密強制CVars只應放即時驗證清單。 -不在戰鬥中修改安全CVar。

巨集命令

巨集指令分為字元、戰鬥等指令。

重要三層：

Macro commands
├─ character commands
├─ combat commands
│  ├─ cast / use
│  ├─ cancelaura
│  └─ startattack / stopattack
└─ addon slash commands
   ├─ /eam opt
   ├─ /eam debug
   └─ /eam export

結論：

  • EAM 斜線指令只能進行設定、探測、偵錯、匯出。
  • 不增加戰鬥自動化。
  • 不產生cast/use/cancelaura類行為。

戰鬥日誌

Combat Log / COMBAT_LOG_EVENT_UNFILTERED 是歷史上常見的 AddOn 資料來源，但 12.x 目標與 EAM 重寫無法依賴盲掃。

重要三層：

Combat Log
├─ Combat Log window / file
├─ COMBAT_LOG_EVENT_UNFILTERED
│  ├─ source
│  ├─ destination
│  ├─ prefix
│  └─ suffix
└─ EAM boundary
   ├─ not primary source
   ├─ no heavy parsing
   └─ use event services instead

結論：

  • 12.x 的 EAM 不以 CLEU 作為光環/cooldown 主要來源。
  • 僅在必要時除錯或非熱路徑檢查時參考。
  • 未建立類似WeakAura的戰鬥解析器。

轉義序列/超鏈接

UI escape strings 和 Hyperlinks 是偵錯文字、工具提示、匯入/export 的風險區。

重要三層：

Escape sequences
├─ color
├─ texture
└─ reset

Hyperlinks
├─ link format
│  ├─ color prefix
│  ├─ type:payload
│  └─ display text
├─ inspection
│  ├─ SetItemRef
│  └─ ExtractHyperlinkString
└─ EAM use
   ├─ spell link display
   ├─ item link display
   └─ debug-safe export

結論：

  • import/export 不宜解析秘密匯出的超連結文字。
  • 工具提示 spellID/itemID 顯示可以保留，但必須和執行時間事實分開。
  • 偵錯匯出要轉義管道/超連結類文字。

  • 12.0.7 API 摘要已發佈；仍需以實機驗證確認 EAM 行為。
  • 12.0.5 的 formatter/duration/table.freeze 已寫入 Docs/10_WARCRAFT_WIKI_12X_API_NOTES.md。

HOWTOs

EAM Implementation Orientation Summary

WoW API

WoW API is the main runtime API entry. EAM rewrite should preferentially find the corresponding namespace from the API system instead of retaining the old global wrapper.

Three important layers:

WoW API
├─ API systems
│  ├─ C_UnitAuras
│  │  └─ AuraService
│  ├─ C_Spell
│  │  └─ CooldownService / SpellInfoService
│  ├─ C_Item
│  │  └─ ItemCooldownService
│  ├─ C_TooltipInfo
│  │  └─ low-frequency fallback only
│  └─ C_Secrets
│     └─ boundary checks

Conclusion:

  • 12.x is only used in the Retail server C_* namespace.
  • C_Secrets should be encapsulated centrally and do not scatter each UI function.
  • C_TooltipInfo is a fallback source, not a hot path source of truth.

Lua API

Lua API Description WoW uses a Lua 5.1 subset and lacks the operating system/archive I/O library.

Three important layers:

Lua API
├─ basic functions
│  ├─ pcall / xpcall
│  └─ type / select
├─ string
│  ├─ string.match / gsub / format
│  └─ WoW custom string helpers
├─ table
│  ├─ table.create
│  ├─ table.wipe
│  ├─ table.freeze
│  └─ table.isfrozen

Conclusion:

  • string.match is not available when using secret derivative tooltip text for which security has not been confirmed.
  • Hot path avoidance of transient tables, table.insert, massive pairs.
  • table.freeze is only used for immutable constants.

FrameXML API

FrameXML function contains UI helper, pool, EventUtil, TooltipUtil, LinkUtil, etc.

Three important layers:

FrameXML API
├─ Mixins / pools
│  ├─ CreateFramePool
│  ├─ CreateTexturePool
│  └─ CreateFontStringPool
├─ SharedXML
│  ├─ EventUtil
│  ├─ FrameUtil
│  └─ TooltipUtil
└─ UIParent / panels
   ├─ ShowUIPanel
   └─ Toggle*Frame

Conclusion:

  • EAM's UI/IconPool.lua can refer to the Blizzard mining pool mode.
  • Do not call functions that toggle protected panels during combat.
  • TooltipUtil can be used as a reference, but tooltip parsing must be low-frequency and secretly secure.

Gadget API / Gadget Script

Widget API and Widget script handlers are the basis of the EAM renderer, EventRouter, and scheduler.

Three important layers:

Widget API
├─ Frame
│  ├─ RegisterEvent
│  ├─ RegisterAllEvents
│  └─ SetScript
├─ Cooldown
│  ├─ SetCooldownFromDurationObject
│  ├─ SetCountdownFormatter
│  └─ SetCountdownMillisecondsThreshold
└─ FontString
   ├─ SetText
   └─ ClearText

Widget scripts
├─ Frame
│  ├─ OnEvent
│  └─ OnUpdate
├─ Button
│  ├─ OnClick
│  └─ PreClick / PostClick
└─ EditBox
   ├─ OnTextChanged
   └─ OnEnterPressed / OnEscapePressed

Conclusion:

  • RegisterAllEvents only applies to debug/datamining, not the EAM runtime.
  • EAM should have only one EventRouter OnEvent.
  • EAM should have only one scheduler OnUpdate.
  • Cooldown should inherit DurationObject and don't let Lua count seconds per frame.

XML schema Description XML can build UI, but the Lua Widget API can also do most things.

Three important layers:

XML schema

  • The new architecture can retain the simple XML loader, but the execution time graph should break IconPool.
  • Avoid creating a large number of global frame names in XML.
  • Avoid XML OnUpdate.
